# Phase 5 build repair notes

## Source repairs applied

- Fixed the unclosed `NotificationListener<ScrollNotification>` in
  `lib/features/dashboard/pages/reader_screen.dart`. The continuous-scroll
  branch now closes both `ListView.builder` and `NotificationListener` before
  the `PageView.builder` alternative. Existing continuous scrolling and
  rotation controls (0°, 90°, 180°, 270°) are retained.
- Changed direct `PdfDocument` cleanup from the nonexistent `close()` method to
  `await document.dispose()` in the reader validation path and comic import
  validation path.
- Made `main()` asynchronous and awaited `pdfrxFlutterInitialize()` before
  `runApp`, so initialization completes before direct PDF document operations.
- Pinned `pdfrx` to 2.4.5. The pdfrx changelog identifies 2.4.5 as the release
  containing the nullable PDF file-cache access fix. This release's published
  minimum Dart SDK is 3.10. The package constraint is therefore raised to
  `>=3.10.0 <4.0.0`. The exact version is pinned to avoid silently resolving
  to later pdfrx releases with newer Flutter requirements.
- Changed the library-provider error logger to print the caught stack trace as
  text instead of calling `debugPrintStack`. The supplied test log shows
  Flutter's stack demangler asserting on `stack_trace` async-gap frames inside
  that logger; the original caught database error remains visible in logs.

## Preserved source features

- Continuous vertical scrolling remains available.
- Page rotation options remain 0°, 90°, 180°, and 270°.
- The reader's existing page navigation, fit settings, progress tracking, and
  PDF viewer widget remain in place.
- Existing ZIP/CBZ import and PDF viewing/import code remain in place.
- No tests were removed, skipped, or weakened.
- No Flutter SDK files or Pub Cache files were edited.

## Important pre-existing limitation

The supplied source explicitly reports CBR and CB7 as unsupported because the
libarchive/7-Zip backend is not present. This repair did not invent placeholder
support or remove those existing error messages. A real archive backend is
still required before CBR/CB7 can be claimed as supported.

## Verification status

This editing environment has no `flutter` or `dart` executable on PATH. As a
result, `flutter pub get`, `dart format lib test`, `flutter analyze`,
`flutter test`, and `flutter build windows` could not be executed here.
The ZIP therefore contains source-level repairs, not a verified Windows build.
Run the requested commands on the Windows development machine. The updated
`pubspec.lock` will be generated by `flutter pub get`; the supplied lockfile
did not contain a pdfrx entry and cannot truthfully be regenerated without
the Dart/Flutter package toolchain.
